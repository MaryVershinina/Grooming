# Конфигурация "Груминг салон"

Конфигурация разработана на платформе 1С Предприятие 8.3 для автоматизации зоосалона: запись клиентов на услуги груминга, учёт питомцев, выполнение заказов, складской и финансовый учёт. Проект реализован на базе Библиотеки стандартных подсистем (БСП): используются подсистемы дополнительных отчётов и обработок, управления доступом, журнала регистрации и обновления информационной базы.

## Возможности

- **Автоматизация записи и обслуживания:** документ «ЗаписьКлиента» с контролем занятости мастера и привязкой к конкретному питомцу и услуге.
- **Складской учёт в реальном времени:** контроль остатков через регистр накопления «ТоварыНаСкладах», автоматическое списание материалов при оказании услуги.
- **Финансовый контур:** учёт поступлений и расходов через регистры «ДенежныеСредства» и «БезналичнаяОплата», формирование кассовой и банковской документации.
- **Аналитика продаж:** отчёты по выручке, популярным услугам и загрузке мастеров на базе регистра «Продажи».
- **Управление задачами:** бизнес‑процесс «ДорегистрацияКлиента» для контроля заполнения недостающих данных и распределения задач между сотрудниками.

## Ключевые навыки и решения

Этот проект демонстрирует следующие компетенции:

- **Работа с управляемыми формами:** все основные документы и справочники реализованы с использованием управляемых форм 1С.
- **Язык запросов 1С:** в модулях объектов и обработках используются запросы с соединениями, группировками и агрегатными функциями для формирования отчётов и проверок (например, контроль занятости мастера при записи).
- **Система компоновки данных (СКД):** отчёты построены на СКД, что позволяет гибко настраивать вывод данных без изменения кода.
- **Интеграция с типовой архитектурой:** конфигурация использует типовые механизмы учёта (регистры, планы видов расчёта, документы движения денежных средств), что важно для работы в реальных проектах.
- **Контроль бизнес‑логики:** в модулях документов реализованы проверки на корректность данных (например, контроль остатков при реализации, проверка графика работы сотрудника).
